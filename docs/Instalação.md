# instalação

## Requisitos

- python 3.10 ou superior
- windows ou linux
- um modelo GGUF de até 900MB

# Passos

```bash git clone https://github.com/FoxxxMaker/Dragonic-4456-CLI```

```cd Dragonic-4456-CLI```

```pip install -r requiriments.txt```

```python main.py```

Você também criar um ambiente virtual.

Se caso seu arquivo for .ZIP:

## Instalação em ZIP:

1. Clique em code (botão verde) e depois vá em ZIP
2. Clique no download zip
3. Extraia a pasta
4. Abra o terminal dentro da pasta
5. Instale as dependências
6. Execute o Main.py
